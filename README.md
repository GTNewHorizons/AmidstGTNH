Advanced Minecraft Interfacing and Data/Structure Tracking (AMIDST)

This is a decompiled version of ForgeAMIDST for minecraft version 1.7.10. <br>
As no 1.7.10 repo existed, and the license on all other Amidst versions is GPL 3.0.

Intended to be used together with Climate Control and Realistic Terrain Generation (RTG) <br>
See https://wiki.gtnewhorizons.com/wiki/Realistic_Terrain_Generation_with_Climate_Control <br>
However, Amidst also works on RWG (RTG and RWG do not work together).

Main Authors of the previous versions of Amidst:<br>
Original by Skidoodle, further modified and enhanced by Zeno410 and Sedridor.
